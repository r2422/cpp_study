# はじめに

## 使い方
このサイトは、Gitの基本コマンドの教科書です。
左のハンバーガーメニューから目次を開いて、各項目へジャンプできます。

> 「Copy」ボタンを押すとクリップボードに保存されます。

# 初期準備

## 初期化 (init)
フォルダをGit管理下に置きます。

```
git init
```

## ユーザー設定
初回のみ実行。名前とメールを登録します。

```
git config --global user.name "Name"
git config --global user.email "email@example.com"
```

# 基本操作

## ディレクトリの移動 (cd)
作業したいフォルダ（ディレクトリ）に移動します。
ドライブが変わる場合は「/d」オプションを付けます。

```
cd /d [フォルダのパス]
```

例: cd /d C:\dev\cpp_study

## 現在の状態を確認 (status)
「今、どのファイルを編集したか」「addし忘れているファイルはないか」を確認します。

```
git status
```

こまめに実行することで、作業のミスを減らすことができます。

---
> 更新を加える際はadd,commitとpush,pullを行えばOKです。

## 追加 (add)
変更をステージ（セーブ準備エリア）に上げます。

```
git add .
```

## 保存 (commit)
今の状態をローカルに記録します。

```
git commit -m "接頭辞: 作業メモ"
```

"作業メモ"には接頭辞をつけるとわかりやすくなります。

| 接頭辞 | 意味 | 説明 |
|---|---|---|
| feat: | feature | 新項目や機能の追加 |
| fix: | fix | 間違い、バグの修正 |
| docs: | documentation | 説明文の追加 |
| style: | style | デザインやコードの整頓 |
| refactor: | refactor | コードの清書(機能は維持) |

# GitHub連携

## 送信 (push)
ローカルの変更をGitHubへ送ります。

```
git push origin main
```

変更後はGithubに訪れて確認しましょう。
F5キーで更新できます。

## 受信 (pull)
GitHubの最新版をPCに取り込みます。

```
git pull origin main
```

# GitHub連携（応用）

## リモートの登録
PC上のリポジトリとGitHubのリポジトリを紐付けます。

```
git remote add origin https://github.com/ユーザー名/リポジトリ名.git
```

## クローン (clone)
GitHubにある既存のプロジェクトを丸ごとPCにコピーします。

```
git clone URL
```

# トラブル解決

## コンフリクトとは？
同じファイルの同じ行を、自分と他の人が同時に書き換えて push/pull しようとすると「衝突（コンフリクト）」が発生します。

この場合、Gitが自動で合体できないため、手動でどちらのコードを残すか決める必要があります。

## 直前のコミットメッセージを直す
「メッセージを打ち間違えた！」という時に、最新のコミットだけ書き換えます。

```
git commit --amend -m "新しいメッセージ"
```

# 便利な一覧表

## ファイルの状態一覧
git status を実行した時に表示される状態の解説です。

| 状態 | 説明 |
|---|---|
| Untracked | 新しく作られた、まだGitが知らないファイル |
| Modified | 変更されたけれど、まだステージに乗っていないファイル |
| Staged | add 済みで、次に commit される準備ができたファイル |
| Unmodified | commit 済みで、変更がないファイル |

# 救急箱

## 変更の取消 (restore)
保存前の変更を捨てて元に戻します。

```
git restore ファイル名
```

## 履歴確認 (log)
これまでのセーブ履歴を一覧表示します。

```
git log --oneline
```

## Git管理の解除（初期化のやり直し）
現在のフォルダにあるGitの設定（履歴など）をすべて削除します。
コマンドプロンプトで「最初からやり直したい」時に使います。

```
rd /s /q .git
```

※実行すると、これまでのコミット履歴が完全に消えるので注意してください。

# ブランチ

## ブランチの作成 (branch)
現在の状態から新しい枝（ブランチ）を作ります。

```
git branch ブランチ名
```

## 切り替え (switch)
作業する枝を切り替えます。

```
git switch ブランチ名
```

## ブランチ関連コマンド
よく使うブランチ操作のまとめです。

| コマンド | 説明 |
|---|---|
| git branch | ブランチの一覧を表示する |
| git branch -d 名 | 指定したブランチを削除する |
| git merge 名 | 別のブランチの変更を取り込む |
